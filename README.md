# MyBike'nCar

Lưu vị trí đỗ xe máy / ô tô (Seasons Avenue), chụp ảnh vị trí đỗ, lịch bảo dưỡng xe. Web app chạy offline trên iPhone.

**Mở app:** https://virtualman209.github.io/mybikencar/ → Safari → Chia sẻ → Thêm vào MH chính.

Xem `HUONG-DAN.md` để biết chi tiết. Dữ liệu và ảnh chỉ lưu trên iPhone, không nằm trong repo này.
